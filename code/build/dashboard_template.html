How the study was donedata, method and limits
  • Data: Open-Meteo / CAMS air quality and ERA5 weather, hourly, one grid cell in central Delhi (28.60N 77.20E), combined into days, plus archived ECMWF weather forecasts (from March 2024; earlier training days use actual weather as a stand-in; every test day uses real forecasts).
  • Two forecasts: "tomorrow" uses everything up to the previous day; "next 7 days" is issued every 7 days for days 1 to 7. Scores use the original µg/m³ scale.
  • No look-ahead: a forecast for day t made h days ahead uses only the weather forecast issued h days before t.
  • Fair testing: four 90-day test periods, one per season, with the training window growing each time; settings were chosen only on data before the first test period. The last test period is exactly the Milestone 2 window.
  • Ensemble is the average of XGBoost, LightGBM, Random Forest, LSTM and GRU, fixed in advance.
  • Limits: modelled grid values rather than station readings, one city, one weather model, each season covered once, extreme days under-predicted.
Words explaineda short glossary
PM2.5
Tiny dust particles in the air (under 2.5 micrometres). India's daily limit is 60 µg/m³ (micrograms per cubic metre).
Forecast: tomorrow / next 7 days
The model predicts the daily average PM2.5 of tomorrow, or of each of the next 7 days.
Test period
Days the models never saw while learning, used only to score them. We use four of 90 days each (one per season); the last is the same test as Milestone 2.
RMSE
Typical size of the forecast error, in µg/m³. Lower is better. Big misses count more.
MAE
Average size of the error, in µg/m³. Lower is better.
MAPE
Error as a percentage of the real value. Lower is better.
R² (fit)
How much of the ups and downs the forecast captures. 1 is perfect, 0 is no better than the average.
Right category
Share of days where the forecast names the right pollution level (Good, Satisfactory, Moderate, Poor, Very poor, Severe).
ARIMA, SARIMA, Naive
Classical models from Milestone 2. "Naive" simply repeats yesterday's value.
XGBoost, LightGBM, Random Forest, Ridge
Machine-learning models that learn rules from many inputs.
LSTM, GRU
Deep-learning models that read the last few weeks as a sequence.
Prophet
A trend-and-season model from Meta.
Ensemble
The average of several models; usually steadier than any single one.
Weather forecast input
The weather forecast for the target day, issued days earlier, used as an extra input.
SHAP
A way to show which inputs a model relied on most.
Significance test
Checks whether a difference between two models is real or could be luck.
